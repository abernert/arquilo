# ARQUILO

Agentic Runtime for Quality, Unified Iteration, Logging and Orchestration.

A lightweight Markdown-task orchestrator with independent review, bounded
correction loops and retained run logs. Python 3.11+, standard library only.
A separately installed and authenticated Codex CLI is required for model calls.

Initial public preview: 0.1.0. Documentation and regression tests follow in this publication change.
This is not a production certification.
