# Community conduct

Be respectful, specific and constructive. Critique code and arguments, not people.
Harassment, discrimination, threats, impersonation and publishing someone else's
private information are not acceptable in project spaces. Respect differing
backgrounds, experience levels and reasonable technical disagreement.

Keep discussion relevant and make room for clarification. Maintainers may edit
or remove harmful content and limit participation where necessary, taking the
context and severity into account. Report concerns privately where possible;
if no private route is available, request one without publishing sensitive details.
These guidelines apply to issues, pull requests and other project-managed spaces.
